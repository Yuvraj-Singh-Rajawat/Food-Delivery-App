# Food Delivery Application


### [Food Delivery Application – Live Demo](https://food-on-finger.onrender.com/)


Welcome to the **Food Delivery Application**! This web application enables seamless online food ordering. Built with a powerful tech stack, including **Node.js**, **Express**, and **Mongoose** for the backend, and **CSS** and **JavaScript** for the frontend, it ensures a smooth user experience. The application uses **JSON Web Tokens (JWT)** for secure authentication and **bcrypt** for password hashing.
